Documentación

Listas Dobles

Cada nodo tiene referencia al siguiente y al anterior.

Listas Circulares

El último nodo apunta nuevamente al primero.

Características

  • Recorrido bidireccional.
  • Estructura dinámica.
  • Conexión circular opcional.
  • Inserciones eficientes.

Casos de uso

  • Reproductores de música.
  • Sistemas operativos.
  • Buffers circulares.
  • Gestión de memoria.

Ejemplos Resueltos

Ejemplo 1 · Nodo doble


class Nodo {
    int dato;
    Nodo siguiente;
    Nodo anterior;
}

Ejemplo 2 · Lista doble


class ListaDoble {
    Nodo cabeza;
}

Ejemplo 3 · Insertar inicio


public void insertarInicio(int dato) {
    Nodo nuevo = new Nodo();
    nuevo.dato = dato;

    nuevo.siguiente = cabeza;

    if (cabeza != null) {
        cabeza.anterior = nuevo;
    }

    cabeza = nuevo;
}

Ejemplo 4 · Recorrer adelante


Nodo actual = cabeza;

while (actual != null) {
    System.out.println(actual.dato);
    actual = actual.siguiente;
}

Ejemplo 5 · Recorrer atrás


Nodo actual = cabeza;

while (actual != null && actual.siguiente != null) {
    actual = actual.siguiente;
}

while (actual != null) {
    System.out.println(actual.dato);
    actual = actual.anterior;
}

Ejemplo 7 · Nodo circular

Ejemplo 8 · Verificar circularidad


if (actual.siguiente == cabeza) {
    System.out.println("Circular");
}

Ejemplo 9 · Eliminar nodo


actual.anterior.siguiente = actual.siguiente;
actual.siguiente.anterior = actual.anterior;

Ejemplo 10 · Contar nodos


int contador = 0;
Nodo actual = cabeza;

while (actual != null) {
    contador++;
    actual = actual.siguiente;
}
