Arrays y Tipos de Datos

Aprende cómo funcionan los arrays, cómo almacenar información y recorrer estructuras de datos en Java.

⬅ Volver al Inicio

Documentación

¿Qué es un Array?

Un array es una estructura de datos que almacena múltiples valores del mismo tipo en una sola variable.

Utilidad

Permite almacenar, recorrer y procesar datos de forma eficiente.

Características

  • Tamaño fijo.
  • Acceso por índice.
  • Mismo tipo de datos.

Casos de uso

  • Listas de estudiantes.
  • Inventarios.
  • Procesamiento de datos.
  • Videojuegos.

Ejemplos Resueltos

Ejemplo 1 · Recorrer array


public class Main {
    public static void main(String[] args) {
        int[] numeros = {10, 20, 30, 40};

        for (int n : numeros) {
            System.out.println(n);
        }
    }
}

Ejemplo 2 · Sumar elementos


public class Main {
    public static void main(String[] args) {
        int[] numeros = {5, 10, 15};
        int suma = 0;

        for (int n : numeros) {
            suma += n;
        }

        System.out.println(suma);
    }
}

Ejemplo 3 · Buscar elemento


public class Main {
    public static void main(String[] args) {
        int[] numeros = {3, 7, 9, 12};
        int buscar = 9;
        boolean encontrado = false;

        for (int n : numeros) {
            if (n == buscar) {
                encontrado = true;
            }
        }

        System.out.println(encontrado);
    }
}

Ejemplo 4 · Índices


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};

        for (int i = 0; i < numeros.length; i++) {
            System.out.println(numeros[i]);
        }
    }
}

Ejemplo 5 · Multiplicar


public class Main {
    public static void main(String[] args) {
        int[] numeros = {2, 4, 6};

        for (int n : numeros) {
            System.out.println(n * 2);
        }
    }
}

Ejemplo 6 · Tamaño


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4, 5};
        System.out.println(numeros.length);
    }
}

Ejemplo 7 · Strings


public class Main {
    public static void main(String[] args) {
        String[] nombres = {"Ana", "Luis", "Pedro"};

        for (String n : nombres) {
            System.out.println(n);
        }
    }
}

Ejemplo 8 · Menor valor


public class Main {
    public static void main(String[] args) {
        int[] numeros = {8, 2, 10, 1};
        int menor = numeros[0];

        for (int n : numeros) {
            if (n < menor) {
                menor = n;
            }
        }

        System.out.println(menor);
    }
}

Ejemplo 9 · Contar


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};
        int contador = 0;

        for (int n : numeros) {
            contador++;
        }

        System.out.println(contador);
    }
}

Ejemplo 10 · Matriz


public class Main {
    public static void main(String[] args) {
        int[][] matriz = {
            {1, 2},
            {3, 4}
        };

        System.out.println(matriz[1][1]);
    }
}
