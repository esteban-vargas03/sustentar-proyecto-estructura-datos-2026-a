Documentación

¿Qué son las estructuras de datos?

Son formas organizadas de almacenar, gestionar y manipular información dentro de un programa.

Utilidad

Permiten optimizar operaciones como búsqueda, inserción, eliminación y organización de datos.

Características

  • Organizan información de forma eficiente.
  • Mejoran el rendimiento de los programas.
  • Facilitan el desarrollo de algoritmos.

Ejemplos Resueltos

Ejemplo 1 · Declarar un Array

Declaración básica de un array en Java.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};
        for (int n : numeros) {
            System.out.println(n);
        }
    }
}

Ejemplo 2 · Sumar valores

Suma todos los elementos de un array.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {5, 10, 15};
        int suma = 0;

        for (int n : numeros) {
            suma += n;
        }

        System.out.println(suma);
    }
}

Ejemplo 3 · Buscar elemento

Busca un número dentro de un array.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {2, 4, 6, 8};
        int buscar = 6;
        boolean encontrado = false;

        for (int n : numeros) {
            if (n == buscar) {
                encontrado = true;
            }
        }

        System.out.println(encontrado);
    }
}

Ejemplo 4 · Recorrer con índice

Recorre un array usando índices.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};

        for (int i = 0; i < numeros.length; i++) {
            System.out.println(numeros[i]);
        }
    }
}

Ejemplo 5 · Multiplicar elementos

Multiplica cada elemento por 2.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {2, 3, 4};

        for (int n : numeros) {
            System.out.println(n * 2);
        }
    }
}

Ejemplo 6 · Tamaño del array

Muestra el tamaño del array.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4, 5};
        System.out.println(numeros.length);
    }
}

Ejemplo 7 · Array de textos

Recorre un array de Strings.


public class Main {
    public static void main(String[] args) {
        String[] nombres = {"Ana", "Luis", "Pedro"};

        for (String n : nombres) {
            System.out.println(n);
        }
    }
}

Ejemplo 8 · Número menor

Encuentra el número menor.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {8, 2, 10, 1};
        int menor = numeros[0];

        for (int n : numeros) {
            if (n < menor) {
                menor = n;
            }
        }

        System.out.println(menor);
    }
}

Ejemplo 9 · Contar elementos

Cuenta los elementos del array.


public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};
        int contador = 0;

        for (int n : numeros) {
            contador++;
        }

        System.out.println(contador);
    }
}

Ejemplo 10 · Matriz bidimensional

Acceso a una matriz 2D.


public class Main {
    public static void main(String[] args) {
        int[][] matriz = {
            {1, 2},
            {3, 4}
        };

        System.out.println(matriz[1][1]);
    }
}
