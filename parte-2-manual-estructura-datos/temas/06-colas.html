Colas (Queue)

Documentación

¿Qué es una Cola?

Una cola es una estructura de datos que sigue el principio FIFO (First In First Out).

Características

  • El primero en entrar es el primero en salir.
  • Inserción al final.
  • Eliminación al inicio.
  • Estructura lineal.

Casos de Uso

  • Impresoras.
  • Sistemas operativos.
  • Procesos en espera.
  • Atención al cliente.

Ejemplos Resueltos

Ejemplo 1 · Crear Cola

Queue<Integer> cola = new LinkedList<>();

Ejemplo 2 · Insertar Elemento

cola.offer(10);

Ejemplo 3 · Eliminar Elemento

cola.poll();

Ejemplo 4 · Ver Primer Elemento

System.out.println(cola.peek());

Ejemplo 5 · Verificar Vacía

System.out.println(cola.isEmpty());

Ejemplo 6 · Tamaño de la Cola

System.out.println(cola.size());

Ejemplo 7 · Recorrer Cola

for (Integer numero : cola) {
    System.out.println(numero);
}

Ejemplo 8 · Limpiar Cola

cola.clear();

Ejemplo 9 · Cola de Strings

Queue<String> nombres = new LinkedList<>();

nombres.offer("Camilo");
nombres.offer("Mauricio");

Ejemplo 10 · Cola Completa

Queue<Integer> cola = new LinkedList<>();

cola.offer(1);
cola.offer(2);

System.out.println(cola.poll());
