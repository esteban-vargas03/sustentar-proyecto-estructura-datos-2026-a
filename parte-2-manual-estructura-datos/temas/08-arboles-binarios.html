¿Qué es un Árbol Binario?

Un árbol binario es una estructura jerárquica donde cada nodo puede tener máximo dos hijos.

Características

  • Estructura jerárquica.
  • Nodo raíz.
  • Subárbol izquierdo y derecho.
  • Recorridos especializados.

Casos de Uso

  • Sistemas de búsqueda.
  • Bases de datos.
  • Compiladores.
  • Organización jerárquica.

Ejemplos Resueltos

Ejemplo 1 · Nodo Árbol

class Nodo {

    int dato;
    Nodo izquierdo;
    Nodo derecho;

}

Ejemplo 2 · Crear Raíz

Nodo raiz = new Nodo();

Ejemplo 3 · Insertar Hijos

raiz.izquierdo = new Nodo();
raiz.derecho = new Nodo();

Ejemplo 4 · Recorrido InOrden

inOrden(raiz.izquierdo);

System.out.println(raiz.dato);

inOrden(raiz.derecho);

Ejemplo 5 · Recorrido PreOrden

System.out.println(raiz.dato);

preOrden(raiz.izquierdo);

preOrden(raiz.derecho);

Ejemplo 6 · Recorrido PostOrden

postOrden(raiz.izquierdo);

postOrden(raiz.derecho);

System.out.println(raiz.dato);

Ejemplo 7 · Verificar Vacío

if(raiz == null){

    System.out.println("Vacío");

}

Ejemplo 8 · Altura Árbol

int altura(Nodo nodo){

    if(nodo == null){
        return 0;
    }

    int izquierda = altura(nodo.izquierdo);
    int derecha = altura(nodo.derecho);

    return 1 + Math.max(izquierda, derecha);
}
