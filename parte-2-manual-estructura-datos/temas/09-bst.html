¿Qué es un BST?

Un Binary Search Tree es un árbol binario donde los nodos menores van a la izquierda y los mayores a la derecha.

Características

  • Búsqueda eficiente.
  • Datos ordenados.
  • Inserción dinámica.
  • Recorridos rápidos.

Casos de Uso

  • Sistemas de búsqueda.
  • Índices de datos.
  • Bases de datos.
  • Gestión jerárquica.

Ejemplo 3 · Insertar Nodo

public Nodo insertar(Nodo raiz, int valor){

    if(raiz == null){
        Nodo nuevo = new Nodo();
        nuevo.dato = valor;
        return nuevo;
    }

    if(valor < raiz.dato){
        raiz.izquierdo = insertar(raiz.izquierdo, valor);
    } else {
        raiz.derecho = insertar(raiz.derecho, valor);
    }

    return raiz;
}

Ejemplo 4 · Buscar Nodo

public boolean buscar(Nodo raiz, int valor){

    if(raiz == null){
        return false;
    }

    if(raiz.dato == valor){
        return true;
    }

    if(valor < raiz.dato){
        return buscar(raiz.izquierdo, valor);
    } else {
        return buscar(raiz.derecho, valor);
    }
}

Ejemplo 8 · Altura BST

int altura(Nodo nodo){

    if(nodo == null){
        return 0;
    }

    int izq = altura(nodo.izquierdo);
    int der = altura(nodo.derecho);

    return 1 + Math.max(izq, der);
}
