Pilas (Stack)

Estructura de datos LIFO: el último elemento en entrar es el primero en salir.

⬅ Volver al Inicio

Documentación

¿Qué es una pila?

Es una estructura LIFO (Last In First Out).

Características

  • Inserción por la cima.
  • El último en entrar es el primero en salir.
  • Acceso restringido.
  • Estructura lineal.

Casos de uso

  • Deshacer acciones.
  • Historial de navegación.
  • Recursividad.
  • Compiladores.

Ejemplos Resueltos

Ejemplo 1 · Crear pila


Stack<Integer> pila = new Stack<>();

Ejemplo 2 · Push


pila.push(10);

Ejemplo 3 · Pop


pila.pop();

Ejemplo 4 · Peek


System.out.println(pila.peek());

Ejemplo 5 · Vacía


System.out.println(pila.isEmpty());

Ejemplo 6 · Tamaño


System.out.println(pila.size());

Ejemplo 7 · Buscar


System.out.println(pila.search(10));

Ejemplo 8 · Recorrer


for (Integer n : pila) {
    System.out.println(n);
}

Ejemplo 9 · Limpiar


pila.clear();

Ejemplo 10 · Uso completo


Stack<String> pila = new Stack<>();

pila.push("A");
pila.push("B");

System.out.println(pila.pop());
