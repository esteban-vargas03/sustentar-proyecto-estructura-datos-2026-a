¿Qué es una Tabla Hash?

Una tabla hash almacena datos usando claves únicas que permiten acceso rápido a los valores.

Características

  • Acceso rápido a datos.
  • Pares clave–valor.
  • Búsquedas eficientes.
  • Uso de función hash.

Casos de Uso

  • Diccionarios.
  • Bases de datos.
  • Autenticación.
  • Caché de aplicaciones.

Ejemplos Resueltos

Ejemplo 1 · Crear HashMap

HashMap<Integer, String> mapa = new HashMap<>();

Ejemplo 2 · Insertar

mapa.put(1, "Juan");

Ejemplo 3 · Obtener

System.out.println(mapa.get(1));

Ejemplo 4 · Eliminar

mapa.remove(1);
