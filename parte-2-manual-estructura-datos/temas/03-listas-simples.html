Listas Enlazadas Simples

Aprende cómo funcionan las listas enlazadas simples, nodos, referencias y recorrido dinámico de datos.

Documentación

¿Qué es una lista enlazada?

Es una estructura de datos dinámica formada por nodos conectados mediante referencias.

Utilidad

Permite almacenar y gestionar datos de forma dinámica sin tamaño fijo.

Características

  • Estructura dinámica.
  • Uso de nodos.
  • No requiere tamaño fijo.
  • Acceso secuencial.

Casos de uso

  • Historial de navegación.
  • Reproductores multimedia.
  • Navegadores web.
  • Sistemas dinámicos.

Ejemplos Resueltos

Ejemplo 1 · Nodo


class Nodo {
    int dato;
    Nodo siguiente;

    public Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}

Ejemplo 2 · Lista


class Lista {
    Nodo cabeza;

    public Lista() {
        cabeza = null;
    }
}

Ejemplo 3 · Insertar inicio


public void insertar(int dato) {
    Nodo nuevo = new Nodo(dato);
    nuevo.siguiente = cabeza;
    cabeza = nuevo;
}

Ejemplo 4 · Recorrer


public void mostrar() {
    Nodo actual = cabeza;

    while (actual != null) {
        System.out.println(actual.dato);
        actual = actual.siguiente;
    }
}

Ejemplo 5 · Buscar


public boolean buscar(int valor) {
    Nodo actual = cabeza;

    while (actual != null) {
        if (actual.dato == valor) {
            return true;
        }
        actual = actual.siguiente;
    }

    return false;
}

Ejemplo 6 · Contar nodos


public int contar() {
    int contador = 0;
    Nodo actual = cabeza;

    while (actual != null) {
        contador++;
        actual = actual.siguiente;
    }

    return contador;
}

Ejemplo 7 · Eliminar inicio


public void eliminar() {
    if (cabeza != null) {
        cabeza = cabeza.siguiente;
    }
}

Ejemplo 8 · Vacía


public boolean estaVacia() {
    return cabeza == null;
}

Ejemplo 9 · Primero


public int obtenerPrimero() {
    return cabeza.dato;
}

Ejemplo 10 · Insertar final


public void insertarFinal(int dato) {
    Nodo nuevo = new Nodo(dato);

    if (cabeza == null) {
        cabeza = nuevo;
        return;
    }

    Nodo actual = cabeza;

    while (actual.siguiente != null) {
        actual = actual.siguiente;
    }

    actual.siguiente = nuevo;
}
